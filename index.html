Welcome to the assignment 1 activity

This is the the first assignment where basic javascript skills are learnt and shown in the different webpages provided on the website. The website features a grade converter which can convert any number from 0 to 100 into a grade letter, a staff page that orders all the staff by name and salary, lastly a temperature converter that will provide to the user temperature in Celsius, Fahrenheit, and Kelvin. The main page will display the image of a fox plush after 10 seconds.
